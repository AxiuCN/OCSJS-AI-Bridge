## 1. 题库配置接入（通过）

- **契约比对**：`ocs-answerer-wrapper.json.example` 与 OCSJS 原版 `AnswererWrapper` 定义逐字段一致（`url` / `method` / `responseType` / `type` / `headers` / `data` / `handler`）
- **原版行为核对**：`env` 只含 `title` / `options` / `type`，`data` 占位符由 `resolvePlaceHolder` 替换；`handler` 返回 `[题目, 答案]` 或二维数组
- **真实端到端**：`POST /v1/answer` 返回 `{"code":1,...,"answer":"北京","model":"ollama-local/qwen3.5:9b"}`；`/health`、`/`、`HEAD /health` 均 200，可用于 OCS 探测

## 2. 功能不退化（通过）

测试覆盖题型（single / multiple / choice / judgement / completion / line / fill / reader / reading / matching）、题型别名、选项归一、图片标记与去重、挖空编号、图片读取（data URL / 下载 / 魔术字节嗅探）、答案回填（字母→原文、多选拆分、判断归一、`#` 拼接、复合题保 JSON）。套件清单见 [`测试.md`](测试.md)。

真实上游实测（`npm run smoke`）关键结果：

| 用例 | 结果 |
|---|---|
| 单选（模型返回字母 `B`） | 回填 **"北京"** |
| 多选 + `think` | **"Python#Rust"** |
| 判断题 | **"正确"** |
| 填空（两空） | **"北京#上海"** |
| 原版口径图片题（URL 在题干，服务端自行下载） | 字母 `A` → **"红色"**，取图带超星 `Referer` |
| 选项含英文单词（first/quiet/third） | **"quiet"**，未被拆成字母 |

## 3. 错误处理不静默（通过）

| 场景 | 实际行为 |
|---|---|
| 上游超时 | `code:0` + 请求被中止 |
| 模型不存在 | `code:0` + HTTP 404 详情 |
| 题目有图但一张都读不出 | `code:0`，**不降级** |
| 候选后端无视觉能力 | 跳过并记 `warnings`；全部无视觉则明确报错 |
| 时间预算不足 | 放弃候选，`code:0` 列出原因 |
| 模型输出夹带解释 / Markdown 围栏 | 容错解析并记 `warnings` |
| 答案无法解析成 JSON | 抛错并降级，**不猜答案** |
| 空答案 | 不当作成功，继续降级 |
| 令牌无效 | HTTP 401 |
| 请求体超限 | HTTP 413 |

多后端真实链路（`npm run smoke:multi`）：主候选指向不存在的模型 → 降级到可用候选并成功；降级原因写入 `warnings`；图片题在无视觉候选上被跳过且报错点出每个候选的真实原因。

并发（`npm run smoke:concurrency`）：3 道不同题同时请求，答案无串扰，耗时递增且墙钟约等于最慢请求，说明并发闸在串行化。

按题型路由（`npm run smoke:routing`）：两个真实模型分别承接不同题型，响应 `model` 字段证明分流生效。

## 4. 跨平台（Windows 已实测；Linux 由部署时确认）

- Windows：`npm run build` 通过，启动、`/health`、`/v1/answer`、鉴权、超时全部实测通过
- 静态审计：无 `process.platform` / 盘符 / `child_process` / 原生模块；运行期零第三方依赖；纯 ESM
- 跨平台契约测试覆盖：CRLF/LF 配置解析一致、BOM、路径分隔符、URL 拼接、回环 http 与远端 https、部署文件行尾（`.bat` 必须 CRLF、`.service` 必须 LF）、NUL 损坏检查
- **Linux 未在开发环境实测**（开发机无 Linux）；部署前运行 `npm run doctor` 一次性确认，它会打印平台架构并真实请求每个后端

## 可复现命令

```bash
npm run typecheck         # 类型检查
npm test                  # 单元与契约测试
npm run build             # 编译到 dist/
npm run doctor            # 部署自检（环境 / 配置 / 后端连通性）
npm run smoke             # 单后端真实链路
npm run smoke:multi       # 多后端降级
npm run smoke:routing     # 按题型路由
npm run smoke:concurrency # 并发
npm run show-config       # 脱敏配置摘要
```
