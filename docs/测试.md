# 测试

## 命令

```bash
npm test          # 单元与契约测试（tsx --test tests/*.test.ts）
npm run typecheck # 源码 + 测试的类型检查
npm run build     # 编译到 dist/
```

## 套件划分

| 文件 | 覆盖 |
|---|---|
| `tests/config.test.ts` | JSONC、`${ENV}` 展开、配置校验、示例防漂移 |
| `tests/domain.test.ts` | 题型/选项归一、图片标记、挖空、答案回填 |
| `tests/prompt.test.ts` | 指令口径、中立请求模型、附件交错 |
| `tests/upstream.test.ts` | 三种协议请求形状、响应解析、容错、空正文重试 |
| `tests/routing.test.ts` | 候选链、预算、能力过滤、降级、策略钩子 |
| `tests/policy.test.ts` | 策略返回值、异常/超时回退、热重载 |
| `tests/httpapi.test.ts` | 鉴权、限额、探测、错误分流 |
| `tests/shutdown.test.ts` | 优雅关闭 |
| `tests/platform.test.ts` | 换行、路径、URL、部署文件行尾、NUL 检查 |

## 真实链路实测

需要可用的 Ollama（读取 `.env` 的 `OLLAMA_*`）：

```bash
npm run smoke              # 单后端 10 项（含图片题、字母映射）
npm run smoke:multi        # 多后端降级（临时配置）
npm run smoke:routing      # 按题型路由（两个真实模型）
npm run smoke:concurrency  # 并发闸与结果隔离
```

## 部署自检

```bash
npm run doctor   # 环境 / 配置 / 每个后端真实连通性
```

探测超时按 `server.deadline_seconds + 10s` 计算（不低于 30s），避免本地模型冷启动被误判为故障。

## 约定

- 断言必须能真的失败：修 bug 时先确认测试转红，再修复
- 测试不得依赖真实网络（除 `smoke*` 脚本外）
- 跨平台契约测试在 Windows 上即执行，改路径/换行/部署文件后必须跑 `npm test`
